SnapFace

SnapFace is a photo-sharing application I developed while following the Intermediate Angular certification course on OpenClassrooms. It uses HTML, CSS, and Angular for a dynamic and smooth user interface. On the backend, I integrated JSON-Server for data management, providing a lightweight and efficient solution for storing and retrieving information.




Stock Management API

Stock Management API is a backend API developed with Spring Boot, following best practices. It is built on a RESTful architecture with Spring Data and MySQL for efficient data management. Input validation is handled by Spring validators, while Swagger simplifies API documentation. Adhering to Clean Code principles ensures a maintainable, scalable, and high-performance API.




Sports Complex Management System

Developed an academic project for a sports complex management system, enabling efficient management of clients, fields, sports, and ticketing. Worked collaboratively with classmates to build a robust solution using **Spring Boot** on the backend, integrating **Spring Security with JWT**, **Spring Data**, and **Swagger** for API documentation. On the frontend, we used **Refine.js** to create a dynamic and user-friendly interface.
